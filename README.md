# Retrowriter
![](readme/splash.png "Screenshot of Retrowriter")
## More than a text editor!
Retrowriter is more than a simple text editor. It's a text-based virtual world. Dive into your own memories, recorded and/or created by you. Save your memories and relive them years later.
## It's all about memories
This text editor does not save text files, but memories.Save and load your memories whenever you want!
## Be one with the editor
No distractions. If you keep on writing, you will be rewarded.
